# unsolvable

Research notes for a framework that generates word-in-context multiple-choice items resistant to small neural solvers while staying valid for humans. Evaluation runs on Russian Unified State Exam items of this type.

## Main document

The full guide is in Russian:

**[docs/unsolvable-guide.md](docs/unsolvable-guide.md)**

It covers problem setup, how models see the task, literature, open method slots, failure-mode taxonomy, pipeline methods, metrics, experimental protocol, risks, and BibTeX.
